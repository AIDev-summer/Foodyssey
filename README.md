# 푸디세이 (Foodyssey)

프랜차이즈 신메뉴를 **신상**(새로 나와서 계속 파는 메뉴)과 **한정**(기간이 끝나면 사라지는 메뉴·이벤트)으로 나눠 보여 주는 페이지 시안이에요.

## 파일

- `index.html`: 페이지. 더블클릭하면 브라우저에서 열려요.
- `data.js`: 메뉴 데이터. 매주 이 파일만 고치면 돼요.

## 업데이트하는 법

1. `data.js`의 `updated`와 `weekLabel`을 이번 주 날짜로 바꿔요.
2. 새로 나온 메뉴는 `newItems`에, 기간 한정 메뉴나 이벤트는 `limited`에 추가해요.
3. 한정 항목에 `end: "YYYY-MM-DD"`를 넣으면 남은 날(D-day)이 자동으로 계산되고, 날짜가 지나면 자동으로 사라져요. 종료일을 모르면 `end` 대신 `open: "가을 시즌"`처럼 적어요.
4. 가격을 모르면 `price`를 빼면 돼요. 화면에도 표시되지 않아요.

## 소식 확인할 곳

- 뉴스: 네이버 뉴스·구글 뉴스에서 "신메뉴 출시", "한정 판매" 검색
- 브랜드 공식 홈페이지의 신메뉴·이벤트 공지 (가격과 종료일 확인용)
- 브랜드 공식 인스타그램·앱 (출시 예고)
